How it works

Enter your daily electricity usage (kWh/day). Select the main transport you use and enter the kilometers you travel per day. If you use a car, choose gasoline or diesel. Click ESTIMATE to see daily / weekly / monthly / yearly emissions and how many trees are needed to absorb them.

Defaults used

  • Electricity factor: 0.581 kg CO₂ per kWh (editable in code)
  • Transport emission factors (g CO₂ per km):
    • Car (gas): 161
    • Car (diesel): 153
    • Jeepney: 150
    • Tricycle: 56
    • Bus: 1045
    • Motorcycle: 72.55
    • * If using miles, the calculator will convert to kilometers automatically for calculation.
  • Tree absorption defaults (kg CO₂ per year): Narra 147; Mahogany 15.24; Mango 274
